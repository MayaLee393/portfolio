# My Portfolio

Welcome to my personal portfolio!
This is a React-based web application hosted on GitHub Pages. It showcases my projects, technical skills, and blogs. I designed this site to give visitors a quick way to learn more about who I am and what I’ve built.

## Features
Projects: A selection of my coding and design projects with descriptions and links.

Skills: A visual overview of the programming languages and tools I use.

Blog: Short write-ups about personal areas of interest.

## Tech Stack
Frontend: React, HTML, CSS, and Tailwind CSS

Hosting: GitHub Pages

## Folder Structure
```
/public       → Static assets
    /blogs    → blog files
    /projects → project files
/src
    /components → React components
    /pages      → Page-level components
    App.js      → Main app entry
    index.js    → ReactDOM render entry
```

##  Running Locally
If you'd like to run this project locally:

```
git clone https://github.com/mayalee393/portfolio.git
cd portfolio
npm install
npm start
```
